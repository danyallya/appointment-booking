# Aurelle working agreements

- Build for independent beauty and care studios. Keep the visual identity warm, precise and editorial, with rose accents, serif headings and clear booking actions.
- Support phone, tablet, desktop, light and dark themes. Use React Icons, semantic HTML, visible focus and accessible labels.
- Use strict TypeScript, Next App Router and Prisma/PostgreSQL. Keep credentials and real client data out of Git.
- Add or update meaningful tests for each behavior, including important error paths and edge cases.
- Before finishing each day, review prior changes and run lint, typecheck, relevant tests and production build; fix regressions.
- Document dependencies. Do not commit .npmrc, environment secrets or generated output. Never force push.
- Follow DAILY_WORKFLOW.md and complete the scheduled BACKLOG.md item. Update docs and leave concrete next-day criteria. If a check is blocked, state the exact command and reason.
