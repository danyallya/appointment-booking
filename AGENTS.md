# Aurelle working agreements

- Build for independent beauty and care studios. Keep the visual identity warm, precise and editorial, with rose accents, serif headings and clear booking actions.
- Support phone, tablet, desktop, light and dark themes. Use React Icons, semantic HTML, visible focus and accessible labels.
- Use strict TypeScript, Next App Router and Prisma/PostgreSQL. Keep credentials and real client data out of Git.
- Add or update meaningful tests for each behavior, including important error paths and edge cases.
- Before finishing each day, review prior changes and run lint, typecheck, relevant tests and production build; fix regressions.
- Document dependencies. Do not commit .npmrc, environment secrets or generated output. Never force push.
- Follow DAILY_WORKFLOW.md and complete the scheduled BACKLOG.md item. Update docs and leave concrete next-day criteria. If a check is blocked, state the exact command and reason.

## Delivery from Day 02

- Read and follow [DELIVERY-POLICY.md](DELIVERY-POLICY.md). Finish Aurelle Appointment Studio and its own PR panel review, merge and sync before the next portfolio repository, or record an exact external blocker. No concurrent project or subagent work.
- Choose commit counts, boundaries, content and wording from this product's real changes; do not copy a fixed history pattern from other projects.
- Review the latest pushed head and checks in GitHub and merge through this repository's PR panel. Respect required independent approvals; self-review does not replace them.

## Community contribution goals — effective Day 02

- Read [CONTRIBUTING.md](CONTRIBUTING.md) at startup. Integrate its Aurelle Appointment Studio examples and real collaboration opportunities into existing daily/weekly/documentation work. Preserve sequential delivery, product-specific commits and every PR gate.
- Recognition is account-wide and externally awarded. No activity quotas, fake coauthors, manufactured issues, star exchanges or review shortcuts; record actual evidence and uncertainty.
